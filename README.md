# Neon Spark

A modern, animated web experience built with cutting-edge technologies. This project features a stunning dark neon theme with smooth scroll-based animations and energetic movement.

**⭐️📍 View the new live demo:** [Neon Spark GitHub Pages](https://rabayakhanam82-a11y.github.io/neon-spark-repo/)

**📍 View the OG live demo:** [Abdullah Karim HTML GitHub Pages](https://24-25ht.github.io/HTML/)

**📚 Reference repository:** [24-25ht/HTML](https://github.com/24-25ht/HTML)

---

## 🚀 Features

- **Animated Scroll Experience**: Smooth, scroll-triggered animations with sharp neon effects
- **Dark Neon Theme**: High-contrast, visually striking design with vibrant neon gradients
- **Responsive Design**: Fully responsive layout that works seamlessly across all devices
- **Performance Optimized**: Built with modern tools for fast load times and smooth interactions
- **Component Library**: Powered by Radix UI for accessible, composable UI components

## 🎯 Development

### Prerequisites

- [Node.js](https://nodejs.org) (v18 or higher)
- [npm](https://www.npmjs.com) or [yarn](https://yarnpkg.com)

### Setup & Installation

```bash
# Clone the repository
git clone https://github.com/rabayakhanam82-a11y/neon-spark-repo.git
cd neon-spark-repo

# Install dependencies
npm install

# Start development server
npm run dev
```

The development server will start at `http://localhost:5173` with hot module reloading enabled.

### Build for Production

```bash
# Build the project
npm run build

# Preview production build locally
npm run preview
```

### Additional Commands

```bash
# Lint code
npm run lint

# Format code with Prettier
npm run format
```
